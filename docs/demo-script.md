# 演示脚本 / 成单 Runbook（内部用）

> 目标：让客户当面看到"**一个词 → 一整站 SEO 页面自动上线**"，几分钟内完成 → 把单子从"评估"推到"签约"。

## 演示前 30 分钟准备清单

- [ ] `.env` 填好 `DEEPSEEK_API_KEY`（默认 provider，最省 token；或用 `ANTHROPIC_API_KEY` 二选一）
- [ ] **二选一演示路径**（见下），对应准备好
- [ ] **提前完整跑一遍并录屏**（防现场网络/模型抽风，翻车就放录屏，绝不冷场）
- [ ] 决定用哪个行业：**打磨版 PU 合成革**（兜底，零风险）+ 准备好现场接客户的词
- [ ] 浏览器先打开 `output/index.html`（本地样板站）作为"开场镇场"

## 两种演示路径

### 路径 A · 本地预览（最稳，零依赖）👈 推荐开场
```powershell
python run.py industries/pu-leather.yaml --dry-run
```
- 不连任何 WordPress，直接在 `output/` 生成整组 HTML 页面
- 跑完打开 `output/index.html` → 整站可点、互相内链、带配图与 SEO 结构
- **优点**：永不翻车（不依赖客户网络/站点），随时能演

### 路径 B · 真发 WordPress（最震撼）👈 高潮压轴
```powershell
python run.py industries/pu-leather.yaml
```
- 真发到一个**干净测试 WordPress**（固定链接设「文章名」）
- 当面刷新 WP 前台 → 8 页"唰"地全上线
- **优点**：最有冲击力 **缺点**：依赖站点/网络，务必提前彩排

> 建议顺序：先用 A 展示成品质量（开场）→ 再用 B 当面跑一次真发布（高潮）→ 最后现场用**客户自己的词**跑一遍（代入感封单）。

## 现场用客户的词跑（封单杀招）
```powershell
# 复制模板，填客户行业的种子词，删掉 pages: 让它现场排结构
copy industries\_template.yaml industries\live.yaml
# 编辑 live.yaml：seed_keyword 改成客户的词
python run.py industries/live.yaml --dry-run
```

## 话术脚本

**开场**（打开 output/index.html）：
> "先给你看个成品——这一整站、8 个页面、互相内链、带 SEO 结构和配图，全是 AI 自动生成的。我现在当场再给你跑一遍。"

**过程中**（console 在跑）：
> "它在挖词 → 聚成主题簇 → 逐页写内容 → 自动加内链 → 配图 → 发布。这一套你们现在是一个人手工做 1–2 周。"

**收尾**（刷新页面，整站出现）：
> "刚才几分钟，等于你们一个人两周的活。**8 千做这个能跑的真版本你先验证；满意了签全案，3.5–5 万把它做成能切任意行业、能多人用的正式系统，这 8 千从总价里扣。**"

## 客户常见问题 → 标准应答

| 客户问 | 你答 |
|---|---|
| **不同行业内容质量怎么保证？（内功）** | "判断力做成模板里的**评分标准 + 黄金范例**，系统发布前自检打分、不达标不发。判断在发布前就做了，不是全发上去等谷歌数据。前期用 1–3 个案例站校准这套标准。" |
| **不同行业页面不一样，怎么加？** | "模板=行业定义包（页型/术语/内链/评分标准/前端）。结构相近的 0.5–2 天加一个；差异大的单独评估。引擎只做一次，行业是增量。" |
| **能保证排名/询盘吗？** | "**不能，也不会跟你夸海口。** 系统负责高效规范地把站铺出来，提效 5–10 倍；排名取决于内容质量+外链+竞争+持续运营。我卖的是效率工具，不是询盘保证。" |
| **价格能不能少？** | （别先松口）"这个数是按真实工时和行情来的。要控成本可以**砍范围**——比如先不做多人后台、先做一个行业——但不是直接降价。" |
| **代码/IP 会不会被扒？** | "正式版核心跑在托管侧，你们拿到的是能力不是源码；真正的壁垒是内功（评分标准），不在代码里。" |

## 防翻车

- 录屏兜底永远准备好
- 演示站用**自己控制**的测试 WP，别拿客户线上站
- 现场词万一内容不理想，切回打磨版 PU 合成革
- 页数控制在 6–8 页，几分钟跑完，别现场跑几十页
