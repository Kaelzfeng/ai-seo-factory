## 2. 「创建项目」vs「聊天」—— 冲突属实
- 现状:**建项目 = 独立表单页 `/projects`**;聊天**必须在已有项目里**(`/` 无项目就跳 `/projects`)。两套范式没统一,建项目**没进对话、也没进侧栏的对话流**。
- 你的愿景:**开口就聊**("我要做个皮革出口站")→ agent 反问 → 定行业/对标/英文词 → **自动建项目并生成**。现在是"先填表建项目→再聊",顺序拧着。
- **正解**:把"建项目/选行业/种子词"**折叠进对话首轮**。新对话 = 一个空项目草稿;agent 通过反问把 (行业, 对标站, 英文关键词) 补全,确认后落库成项目并开跑。`/projects` 列表页保留作"已有项目"管理即可。

## 3. 愿景缺口:NL + 反问 → 行业 / 对标 / 关键词(未实现)
当前对话是**单发**:打字→`seed`→英文 grounded 管线→流式结果。**没有多轮、没有反问、没有对标发现、没有语言/意图理解。**
要补一个**意图/brainstorm 前置 agent**(对应 pending #27 前半段叙事、#32 上 Google 找对标、#33 NL 改页):
1. 听懂客户自然语言(中/英都行)→ 归纳**大致行业**;
2. **反问**补全:目标市场/语言、买家画像、要对标哪些站(或 agent 自己上 Google SERP 找对标);
3. 从对标 + 行业产出**英文种子词**(而不是把中文直接当 seed);
4. 确认后再进现有确定性管线(接地抓词→规划→生成→质检)。
