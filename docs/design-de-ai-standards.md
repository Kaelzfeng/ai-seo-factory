# 设计规范:去「AI 味」,做内敛企业级中台(2026-06-07)

> 适用于超管后台(`admin/*`)及后续所有自建界面。
> 目标:从"AI 特供版自动化工厂"回到**高端、务实、内敛的企业级专业系统**。
> 底子(Gemini + shadcn 融合)已经够专业,关键是剥掉"AI 正在施法"的炫技外壳。

## 核心判断

界面的"AI 味"来自**堆砌大模型工具的视觉符号 + 叙事结构**(闪电/星星图标、Agent/Skill 黑话、糖果色标签、带圈数字的生成流)。
去味 = **弱化"AI 在施法"的炫技感,强化"专业生产力工具"的确定感与业务属性**。
一句话:把"智能/魔法/Agent"外壳剥掉 → 它就是一个高级的、操控企业内容供应链的 **CMS 增强中台**。

## 四条铁律

### 1. 去符号化(删魔法图标)
- ❌ 禁用:闪电 `bolt`(⚡)、星星/魔棒 `sparkle`/`auto_fix`(✨🪄)、机器人 `smart_toy`、彩虹渐变 `.spark`。
- ✅ 用传统中台/业务图标:`grid_view`/`widgets`(组件)、`deployed_code`(模块)、`account_tree`(分支/聚类)、`sell`(标签)、`fact_check`(核验)、`article`/`description`(内容)、`cloud_upload`(发布)、`palette`(设计)。
- 品牌标识用**单色实底**(`.brandmark` 风格),不用彩虹渐变;不加 shimmer/呼吸/扫光动画。

### 2. 去黑话化(删 AI buzzword)
- ❌ 不把底层技术翻到台面:`Agent`、`Skill`、`agentic`、`Prompt`、`黑箱`、`"去 AI 味"`、`LLM`、`施法`。
- ✅ 按"**解决什么业务问题**"命名(ERP / 内容中台口吻):
  - Agent 与 Skill → **内容自动化流水线 / 策略执行组件**
  - SEO 正文生成 → **结构化内容生成**
  - 内容润色 / 去 AI 味 → **文本合规与风格润色**
  - 确定性质检 → **内容质量核验**
- 副本去技术词:"agentic 引擎可编排可解释" → "**支持按需配置、自由组合的自动化执行逻辑,全链路可追踪、可核验**"。

### 3. 去浮躁感(克制色彩)
- 标签(角色/状态)**降饱和**:≤ 1 个强调色(品牌蓝 `#1A73E8`),其余一律中性灰(zinc)。不要糖果蓝/绿/黄并排。
- 去掉**非必要有色背景块**:提示条不用整块蓝/绿底,改极浅灰底,或仅保留**左侧一条品牌蓝边**(`border-left`)。
- 状态用**低调点 + 文字**(灰/蓝小圆点),不用高饱和 chip。

### 4. 去监控感(别像跑批)
- ❌ 不用"带圈数字的线性流 + 运行中 + 时间预估"那种大模型跑批 / 任务监控样式。
- ✅ 用传统项目管理表达:**横向里程碑步骤条**,或**标准表格**(阶段 / 内容 / 周期 / 状态)。
- 日志式辅助文本(`seed 搜索…`、`differentiator 已采集…`)默认折叠,或缩小减淡,不做视觉焦点。

## 落地清单(改版自检)
- [ ] 全屏搜一遍:无 ⚡✨🪄 / 机器人 / 彩虹渐变。
- [ ] 标题/卡名/副本:无 Agent/Skill/agentic/黑箱/去AI味。
- [ ] 标签:≤ 1 强调色 + 中性灰;无三色并排糖果标签。
- [ ] 提示条:无整块有色底(改浅灰或左侧蓝边)。
- [ ] 流程/路线:里程碑或表格,非带圈数字生成流;日志文本已减淡。

## 量化细则 v2(2026-06-07 加严)

**配色(状态 / 标签)**
- 业务绿(唯一状态正色):`#16A34A`。正常 / 运行中 / 已上线 = 灰字或纯文本 + 该色 Status Dot(7px 圆点),**不要浅色亮底 chip**。
- 属性标签(核心 / 扩展 / 可编程…):中性 `#F3F4F6` 底 + `#4B5563` 字,或透明 + `1px #E5E7EB` 边框;**全部中性、不分色**。
- 全局 ≤ 1 个强调色(品牌蓝 `#1A73E8`);禁亮黄 / 亮绿 / 紫蓝氛围饰色并排。
- 扣分 / 告警进度条用**沉稳暗橙或红褐**(如 `#A0522D`),不用高饱和亮橙(亮橙在白底上仍带新潮 SaaS 味)。

**结构**
- 分割线统一 `1px solid #E5E7EB`;模块去 box-shadow 悬浮感,改一体化 Grid / 分栏面板。
- 流程 / 路线 = 标准表格,表头固定:**执行阶段 · 核心策略 · 时效预估 · 状态**;或横向 Steps 里程碑。禁"数字圆圈 + 连线"生成流。

**文案**
- 禁在 UI 正文出现:英文技术标识符(如 seo-content、differentiator)、代码连接符 `->` `+` `→`。
- 必须保留的技术码:`11–12px` Monospace、`--faint` 色、放卡片角落或 hover。
- 标题 / 副本全业务化口吻(Agent 与 Skill → 内容自动化流水线 / 策略执行单元)。
- 技术标识码即便保留(角落 .adv-code),也要**避开圈内黑话**(antislop / prompt / slop / agentic 等),改用官方学术统计词(`content_uniqueness` / `information_density`)。引擎内部真实维度名可不动,只在**显示层**做映射。

**组件套件**(`static/admin.css`,全 admin 复用以保证一致):
- `.adv-tag` 中性属性标签(`.adv-tag.bd` 边框变体)
- `.adv-status`(+`.ok` 业务绿 / `.warn` / `.plan`)圆点状态
- `.adv-code` 角落技术码(11px mono faint)
