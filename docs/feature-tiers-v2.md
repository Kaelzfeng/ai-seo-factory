## 护城河 / 转售版 —— 「量产不被罚 + 拿去转售」(单独算,绝不 ¥3.5–5万 打包)

**护城河(印钞机核心,客户表里漏了,要补)**
- **去重 / unique 引擎** ★:从一个模板量产成百上千页,却让每页真正独特、彼此不近重复、**扛得住 Google scaled-content/doorway 惩罚**。← 这是"为什么不用站群、不用 Byword"的唯一答案。
- **长期记忆防重复**:记住本站已覆盖哪些 Topic/已发什么,新页生成前比对,从源头防重复(客户把它放进了基础版,要拎出来)。

**全自动 agent 层(付费 premium)**
- 任务编排引擎(Workflow)· 反思与重试(低于阈值自动重生成)· 目标分解器("排名进前 10"→任务链)· 多 Agent 协作 · 实时排名监控与预警(接 GSC)· 链接健康检查

**转售 SaaS 壳**
- 多租户 + 全局 AI 配置 · RBAC 完整权限 · 用量与计费仪表盘(按 Token/API/文章数)· 技能市场/插件系统 · Skill 版本依赖管理 · Skill 审批与沙箱 · 自定义 AI 模型接入 · 导出/导入配置包 · 内容复用引擎 · 内容日历 · 审计日志 · 水印与版权保护

**这一档的成交结构(防扒 + 不被一锤子买断走):**
- 护城河去重模块:**¥4–8万**(或 ¥3–8k/月),不打折核心溢价项。
- 转售壳:**白标 setup ¥7–22万 + per-tenant ¥200–580/租户/月 + 抽成 15–25% + 年度最低承诺 ¥14–36万**。
- **去重核心做成云端黑盒 API**(客户只调用、拿不到算法)+ **源码进 escrow 永不交付**。
- 死磕买断:锚"他未来 3–5 年 ARR × 2.5–4.5 的现值、不含源码、递减式永久授权",底线 ≥ 他 24 个月分成总额。

## 给交付方的两条路(诚实结论)

1. **守 ¥3.5–5万**:就把完整版**砍到上面 A+B+C 的单租户范围**,护城河/转售壳明确**不在内**。客户要那些,另谈护城河版/分成。(用"砍范围"接住低价,不降护城河的价。)
2. **要全套那张 70 行表**:那是 ¥25–35万 / 白标+分成的系统,不是 ¥3.5–5万。用调研锚点跟客户摆事实。

**positioning 一句话**(借客户自己的话):他说"AI 生成 10 分钟的事"——对,所以我们**不靠生成收钱**,靠的是"**量产却每页 unique、扛 Google、还能拆解竞品超越他**"。这正是他愿意付复杂钱的地方,也是护城河该独立收费的依据。
